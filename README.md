# ⚙️ Date Library

A reusable **C++ Date Library** built around the `clsDate` class, designed to simplify common date-related operations in a clean, object-oriented way.  
It provides a complete set of utilities for working with dates, including validation, formatting, comparisons, calendar generation, and advanced date arithmetic.

---

## ✨ Overview :

The library was developed to handle date manipulation scenarios with reliability and flexibility.  
It supports multiple ways to create a date object, including the system date, a string input, day/month/year values, and a day-order-in-year format.  
The class is also designed with encapsulation in mind, exposing date properties through controlled getters and setters.

---

## 🚀 Features :

### 📅 Date Creation & Parsing :
🔹 Create a date from the system date  
🔹 Create a date from a string format such as `dd/mm/yyyy`  
🔹 Create a date from day, month, and year values  
🔹 Create a date from the day order in a year  

### ✅ Validation & Formatting :
🔹 Validate whether a date is correct  
🔹 Convert a date to a readable string format  
🔹 Print dates directly to the console  

### ⏳ Leap Year & Time Calculations :
🔹 Detect leap years  
🔹 Calculate the number of days, hours, minutes, and seconds in a year  
🔹 Calculate the number of days, hours, minutes, and seconds in a month  

### 🗓️ Calendar Utilities :
🔹 Determine the day of the week for any date  
🔹 Retrieve short day and month names  
🔹 Print a monthly calendar  
🔹 Print a full yearly calendar  

### 📈 Date Arithmetic :
🔹 Add or subtract one day, week, month, year, decade, century, or millennium  
🔹 Add or subtract a custom number of days, weeks, months, or years  
🔹 Move forward or backward through time while maintaining valid date values  

### 📊 Date Comparison & Difference :
🔹 Compare two dates  
🔹 Check whether a date is before, after, or equal to another  
🔹 Calculate the difference in days between two dates  
🔹 Determine whether a date is the last day of the month or year  

### 🧭 Business Day & Vacation Logic :
🔹 Detect weekends and business days  
🔹 Calculate business days between two dates  
🔹 Calculate vacation days  
🔹 Determine the expected return date after a vacation period
